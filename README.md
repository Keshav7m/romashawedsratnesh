# Romasha & Ratnesh — Wedding Invitation

Static site. Open `index.html` in a browser, or deploy to GitHub Pages.

## Deploy
1. Push this folder to a GitHub repo.
2. Settings → Pages → Branch: `main`, folder: `/ (root)`.

## Files
- `index.html` — the invitation
- `support.js` — runtime
- `assets/` — images and background music
